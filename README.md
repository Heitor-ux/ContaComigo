# ContaComigo

Projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento de Interfaces**, com o objetivo de criar uma aplicação web para gerenciamento e divisão de despesas compartilhadas.

## Sobre o projeto

O ContaComigo é uma aplicação web voltada ao gerenciamento de despesas compartilhadas, permitindo que usuários organizem gastos, acompanhem saldos e realizem divisões financeiras entre integrantes de diferentes grupos.

## Objetivo

Facilitar o controle de despesas compartilhadas, oferecendo uma interface intuitiva para registrar gastos, visualizar movimentações e acompanhar os valores que cada participante deve pagar ou receber.

## Funcionalidades previstas

- Dashboard com resumo financeiro.
- Gerenciamento de grupos.
- Registro e organização de despesas.
- Divisão de valores entre participantes.
- Histórico de atividades.
- Visualização de saldos e acertos de contas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Contexto acadêmico

Projeto desenvolvido como atividade acadêmica da disciplina de Desenvolvimento de Interfaces.
